## 🗺️ الخريطة الأم — منظر من فوق

```
              ▲ الغابة / TREELINE البعيد
   ┌──────────────────────────────────────────┐
   │                                          │
   │                 🌲                       │
   │            شجرة الصنوبر                  │
   │              (0 , 0)                     │
   │                                          │
   │        ◯ بيت الأرنب                      │
   │        (-0.5 , -0.5)                     │
   │                                          │
   │                          ▓▓▓             │
   │  ══ الحبل ═════════════►  صخرة           │
   │                          (3 , -2)        │
   │                     🦊 جحر الثعلب        │
   │                        (3.5 , -4)       │
   └──────────────────────────────────────────┘
                    ▲ الكاميرا الأم (جنوب)
```

| العنصر | الإحداثي (س = شرق · ص = شمال) |
|---|---|
| **الشجرة** | `0 , 0` — المركز |
| **بيت الأرنب** | `-0.5 , -0.5` — قاعدة الجذع، مائل شوية لليسار |
| **الصخرة** | `+3 , -2` — يمين، وأقرب للكاميرا |
| **جحر الثعلب** | `+3.5 , -4` — ورا الصخرة، أقصى اليمين |
| **الجزرة** | `-1 , -1.2` — قدام بيت الأرنب على العشب |
| **الحبل** | من الجزرة ← يمر تحت العشب ← **ملفوف على الصخرة** |

### 🧱 قاعدة الاتصال الفيزيائي
الحبل **لازم يكون مرئي ومتواصل** في كل لقطة كتظهر فيه. إذا انقطع بصرياً، المشهد يبان مفكّك.

## 🎬 اللقطات الستة

---

### SC01 — الفخ (The Trap Is Set)
**المدة:** 5s · **الكاميرا:** Wide · منخفضة · ثابتة · جنوب

| | |
|---|---|
| **الموقع** | الجزرة `-1,-1.2` · الثعلب جاثي جنبها `-1.3,-1.5` · الصخرة يمين |
| **الأرنب** | ❌ **ما يبانش** — راهو في بيته |
| **الثعلب** | جاثي على أربع، يربط حبل حول جزرة عملاقة، لسانو خارج من التركيز، عينيه ضيقة |
| **الحبل** | يمر من الجزرة ← تحت لليسار ← ملتوي على الصخرة |
| **الحدث** | يشدّ الحبل للتأكد، يمسح يديه، يضحك بلا صوت، يخبّي روحو **ورا الصخرة** |

---

### SC02 — الخروج (The Emergence)
**المدة:** 5s · **الكاميرا:** Medium-Close · مستوى الأرض (~40cm) · ثابتة

| | |
|---|---|
| **الموقع** | كادر على بيت الأرنب `-0.5,-0.5` قدام-يسار |
| **الأرنب** | راسو غير خارج من الفتحة — **ودنيه أول حاجة تطلع**، من بعد عينيه |
| **التعبير** | العينين كبار بزاف · البؤبؤ يتوسّع · فمو يتحلّ · **خيط لعاب** كينزل |
| **الثعلب** | **خلف الصخرة يمين** — غير راسو وقبعته باينين فوق الصخرة |
| **الحدث** | الأرنب كيشمّ الهواء، ومن بعد كيطلع نصّو، عينيه معلّقة في الجزرة |

---

### SC03 — الشدّ (The TUG)
**المدة:** 6s · **الكاميرا:** Medium-Wide · منخفضة · ثابتة

| | |
|---|---|
| **الموقع** | الجزرة + الأرنب **يسار** · الحبل يمر في وسط الكادر · الثعلب **يمين** عند الصخرة |
| **الثعلب** | ⭐ **هو اللي كيسحب** — كفّينه على الحبل، مايل للور 45°، كعبيه مغروزين، ذيلو للور للتوازن |
| **الأرنب** | ماسك الجزرة، **كيتجرّ** على العشب، جواربو كتزحلق، ودنيه للور، خدوده منفوخة، **رافض يطلّق** |
| **الحبل** | ⚠️ **خط واحد متوتر** من يدّ الثعلب حتى الجزرة · ما يتبدّلش يد · ما ينقطعش |
| **الحدث** | شدّة أولى عنيفة → الأرنب يتزحلق → شدّة ثانية → **تعادل** |

> ⭐ **الثعلب = الساحب · الأرنب = المتجرّر.** هذا اللي كيصنع النكتة.

---

### SC04 — الانقلاب (The Snap-Back)
**المدة:** 6s · **الكاميرا:** Wide · ثابتة

| | |
|---|---|
| **الموقع** | نفس الكادر الأم |
| **الجزرة** | **تنفلت** — الحبل انقطع من جهة الصخرة |
| **الأرنب** | كيطير **للور** على ظهرو، الجزرة في يدّو، ودنيه لتحت، ساقيه في الهوا |
| **الثعلب** | 🔴 **الانقلاب:** كيس خيش كبير كيطير من ورا الصخرة و**كيرتّب على راسو** — القبعة كتطير |
| **الحدث** | ردّ الفعل العكسي. الفخ اللي وجّه للجزرة ضرب صاحبو |

> **القاعدة الفيزيائية:** الشدّ يروح للجهة المقابلة. الأرنب ← يسار · الكيس ← يمين.

### SC05 — العالق (Tangled Fox)
**المدة:** 5s · **الكاميرا:** Medium · يمين الكادر

| | |
|---|---|
| **الموقع** | الثعلب جالس على الأرض `+3,-2.5` · الأرنب واقف قدّامو |
| **الثعلب** | 🔴 **ملفوف في كيس الخيش** · القبعة مايلة على عينيه · **كف أسود واحد غير خارج** كيتلوّح |
| **الأرنب** | واقف، ماسك الجزرة العملاقة كيما الكأس، **كيضحك بلا صوت**، كيأشّر بصباعو |
| **الحدث** | الأرنب يدور حواليه ويتنمّر عليه براحة |

### SC06 — المكافأة (The Payoff) — END
**المدة:** 6s · **الكاميرا:** Wide · ثابتة · **الكادر الأم**

| | |
|---|---|
| **الموقع** | الأرنب **فوق الصخرة** · الثعلب تحت عند قاعدتها |
| **الأرنب** | جالس على الصخرة، **ساقيه مرفرفين**، كياكل الجزرة، **كيغمز للكاميرا** |
| **الثعلب** | تحت، مازال كيتخبّط في الكيس، القبعة على عينيه |
| **الإضاءة** | **أدفأ شوية** — الضوء الذهبي |
| **الحدث** | هدوء. الأرنب يرمي **قشّرة جزرة** على راس الثعلب. سقوط. |
