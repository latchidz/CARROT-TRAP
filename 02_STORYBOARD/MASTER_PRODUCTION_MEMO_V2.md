# 1) السلسلة السببية (CAUSAL CHAIN) — قانون ملزم

```
①  الثعلب يربط الحبل على الجزرة العملاقة          →  الطعم + خط السحب
②  الثعلب يرمي كيس الخيش فوق الصخرة               →  شبكة الصيد (معلّقة، جاهزة)
③  الثعلب يخبّي روحو ويشدّ طرف الحبل              →  جاهز للتنفيذ
④  الأرنب يطلع ويشمّ الجزرة                        →  الضحية داخل الفخ
⑤  الثعلب يشدّ بقوة                                →  الأرنب يتجرّ
⑥  الأرنب يفلت / يزحلق                            →  الحبل يرتخي
⑦  الثعلب مايل للور 45° بكل وزنو                  →  يفقد التوازن
⑧  ظهرو يضرب الصخرة                              →  الارتطام
⑨  الكيس اللي فوق الصخرة يتقلب ويطيح             →  السقوط
⑩  الكيس يبتلع راسو وكتافيه                       →  النتيجة
```

**⭐ القانون:** كل لقطة **كيسبب** اللي بعدها. لا حاجة كتظهر من والو.

**⭐ العدالة الشعرية:** الثعلب وقع في **فخّو هو**. الكيس اللي حضّرو للأرنب هو اللي حبسو.

# 3) قفل اتجاه الكاميرا (CAMERA-DIRECTION LOCK)

> هذا القفل **ملزم لكل لقطة**. ما ينعكسش.

```
                    ▲ العمق (شمال)
   ┌──────────────────────────────────────┐
   │              🌲                      │
   │           شجرة الصنوبر               │
   │           الجذع = المحور المركزي     │
   │              │                       │
   │         ◯ الجحر (قاعدة الجذع)         │
   │              │                       │
   │   🐰 الأرنب   │      ▓▓▓ الصخرة      │
   │   (يسار)      │      (يمين + قريب)   │
   │               │      🦊 الثعلب       │
   └──────────────────────────────────────┘
                    ▲ الكاميرا (جنوب)
```

| العنصر | البلاصة | ما تتبدّلش |
|---|---|---|
| **الجذع** | المحور العمودي المركزي | ✅ |
| **الجحر** | قاعدة الجذع · على المحور | ✅ |
| **الصخرة** | يمين الكادر · أقرب للكاميرا | ✅ |
| **الأرنب** | **يسار** الجحر | ✅ |
| **الثعلب** | **يمين** · عند الصخرة | ✅ |
| **الحبل** | من الجزرة (يسار) ← يد الثعلب (يمين) | ✅ |
| **كيس الخيش** | **فوق الصخرة** حتى اللقطة ④ | ✅ |

# 6) اللقطات بالتفصيل

## SC01 — THE SETUP · 6s
| | |
|---|---|
| **الثعلب** | جاثي على ركبة وحدة جنب الجزرة، كيربط الحبل حولها بحلقة مزدوجة (knot) |
| **الجزرة** | عملاقة، على العشب، **يسار** الكادر |
| **الحبل** | من الجزرة ← يمر على العشب ← **طرفو في يد الثعلب** |
| **الحبل الثاني** | ⭐ قطعة حبل قصيرة تربط **كيس الخيش فوق الصخرة** — الكيس **متدلّي/مطوي فوق قمة الصخرة**، واضح بزاف |
| **الحبل من الجزرة** | يمر تحت الصخرة — خط واحد |
| **الجحر** | ساكت، أسود — الأرنب ما زال داخل |
| **التعبير** | لسانو خارج، عينيه ضيقة، ضحكة خبيثة صامتة |

## SC02 — THE BAIT · 5s
- الأرنب: ودنيه تطلع أول → راسو → عينيه على الجزرة → **خيط لعاب**
- الثعلب: نصّو فوق الصخرة، **الكيس جنبو على الصخرة** (باه يبان)
- الحبل: على العشب، خامل

## SC03 — THE HAUL · 6s
- ⭐ **الثعلب هو الساحب** — مايل للور 45°، كفّينه على الحبل
- الأرنب **كيتجرّ**، جواربو كتزحلق
- الحبل **متوتر كالوتر** — خط مستقيم
- الكيس **مازال فوق الصخرة** ورا الثعلب

## SC04 — THE REVERSAL · 6s ⭐ **اللقطة المفتاحية**
| | |
|---|---|
| **قراءة اللقطة** | لازم تبان **4 حوايج في نفس الوقت** |
| **① الحبل** | **مرتخي** — منحني، ماشي متوتر. طرفو الحر كيتلوّح |
| **② الأرنب** | **يديه مفتوحين** (فلّت!) · طايح لور بالتة، الجزرة كتدور جنبو |
| **③ الثعلب** | **طاير للور**، ظهرو **ملامس للصخرة**، ساقيه في الهوا، ذيلو مقلوب |
| **④ الكيس** | **كينزل من فوق الصخرة**، منقلب، **راسو داخل فيه**، القبعة طايرة |
| **الأرضية** | غبار · كوز صنوبر طايحين |

> ⚠️ **ما نيش نصور «انقلاب» مجهول.** نصور **سلسلة**: إفلات → ارتخاء → ارتطام → سقوط الكيس.
> الكيس **جاي من فوق الصخرة** — مصدرو واضح في الكادر.

## SC05 — THE PAYOFF · 5s
- الثعلب: جالس في نفس الكيس، القبعة على عينيه، كفّ أسود خارج
- الأرنب: واقف، الجزرة كيما الكأس، كيضحك بصمت
- الخلفية: الصخرة **بلا كيس** الآن (الكيس على الثعلب) ✅

## SC06 — THE END · 6s
- الأرنب: فوق الصخرة، كياكل، **كيغمز للكاميرا**
- الثعلب: تحت، في الكيس، القبعة جنبو مقلوبة
- قشّرة جزرة تطيح على راسو
