# 🥕 CARROT SPEC — الجزرة العملاقة (FROZEN)

> أي صورة فيها الجزرة **لازم** تحترم هاد المواصفات. المرجع البصري: `REF_CARROT_9x16.png`

---

## الشكل — Shape
```
ONE single fat cone.
Crown  : thick, rounded, blunt.
Taper  : smooth along the whole length.
Tip    : ONE single sharp point. Never forked, never bent, never with limbs.
```

## الحجم — Size
```
Length  = the FOX'S STANDING HEIGHT  (≈ 2× the rabbit's height)
Width   = at the crown, as wide as the rabbit's body
```
> ⛔ ممنوع تصغّر. في SC03 وSC04 القديمين ولّات بحجم الأرنب — هذا كان الخطأ.

## اللون والتفاصيل — Colour & detail
```
Body   : warm saturated orange
Ridges : slightly darker orange horizontal ridges just below the crown
Hairs  : a few fine pale root hairs
Tops   : exactly 5 short bright-green leaf stalks, cut straight, spiky, fanning
```

## الحبل — The Rope
```
ONE thick brown twisted rope.
Tied in a SIMPLE KNOT around the exact MIDDLE of the carrot.
Knot must be VISIBLE in frame whenever possible.
The rope is tied to the CARROT — NEVER to the rabbit, NEVER to the fox's waist.
```

## الاتجاه — Orientation
```
ALWAYS lying FLAT on the ground.
Canonical pose : green LEAVES point LEFT · sharp TIP points RIGHT.
⛔ NEVER standing upright.  ⛔ NEVER floating.  ⛔ NEVER leaning on a tree.
```
> استثناء: أثناء السحب (SC03) الجزرة تنجرّ والطرف يقود. مسموح.

## الموضع — Position
```
Resting position: on the grass immediately LEFT of the burrow mouth,
centred on the same vertical band as the burrow.
```
> ⛔ ممنوع تقفز لليمين. هذي كانت أكبر غلطة في V2.

---

## الكود الجاهز للنسخ في البرومبت

```
ONE GIANT CARROT lying FLAT on the grass — thick rounded crown, tapering to ONE
single sharp point, warm orange body with darker orange ridges near the crown,
5 short bright-green leaf stalks, ONE thick brown twisted rope tied in a SIMPLE
KNOT around its exact MIDDLE. GREEN LEAVES point LEFT, SHARP TIP points RIGHT.
It is GIANT: its length equals the fox's standing height. Never upright, never
floating, never leaning.
```
